CONFIGURATION

添加或编辑构型参数

按下面 3 步添加构型
  1. 命名：当前预设会自动带入；要保留原构型，请先点“新建副本”。
  2. 填写：分别输入两条 RSS 支链的零位几何参数和电机限位。
  3. 保存：点击“检查并保存”，通过检查后会自动加入“几何预设”列表。

构型保存在当前浏览器中；如需备份、换电脑或发给他人，请使用“导出 JSON”。

参数含义与坐标约定（首次填写建议展开）
电机轴上的点 mᵢ
用来确定电机轴“经过哪里”。通常直接取电机输出轴与曲柄相交的转轴中心；它必须位于电机轴线上，并使用基座坐标系表示，单位 mm。
电机轴方向 uᵢ
驱动轴的方向向量，无单位；不必预先归一化，保存时会自动归一化。
曲柄零位向量 aᵢ₀
电机零位时，由 mᵢ 指向曲柄端球副 Aᵢ 的向量，单位 mm。
公共万向副中心 O
两条支链共用同一个 O 点，因此两侧输入会自动同步。若公共基座坐标系原点就在 O，请填 [0, 0, 0]；否则填写 O 在基座坐标系中的坐标，单位 mm。
平台球副向量 bᵢ₀
平台零位时，由 O 指向平台球副 Bᵢ 的固连向量，单位 mm。
连杆长度 Lᵢ
Aᵢ 与 Bᵢ 之间的固定长度，必须大于 0，单位 mm。
零偏与限位
均以角度填写；下限不得大于上限。
公式输入
支持 sin、cos、tan、sqrt、abs、pi/π、括号和 + - * / ^。乘法必须写 *。
角度写法
三角函数中的普通数字默认按度计算，因此 cos(15) 就是 15°；含 pi/π 的公式按弧度计算。cos(15)、cos(15°) 与 cos(pi/12) 等价。
示例
-50*cos(15°)、50*sin(pi/12)、sqrt(2)/2 均可直接填写，保存后仍保留原公式。
数值微调
纯数字可用右侧箭头：整数每次增减 1，保留几位小数就改变最后一位。公式请直接修改表达式。
输入框可以直接写公式 -50*cos(15°)　50*sin(pi/12)　sqrt(2)/2 支持 sin cos tan sqrt abs pi/π；sin(15) 默认表示 15°，含 pi/π 时按弧度计算。电机角输入 15、15° 或 pi/12 都表示 15°。

计算模型与 src/solver.cpp 一致；长度单位为 mm，角度界面使用 °，内部使用 rad。
